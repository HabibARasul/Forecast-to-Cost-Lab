# Forecast-to-Cost Lab

Thesis: Benchmarking Conventional and AI-Driven Approaches for Joint Transportation-Inventory Optimization in Retail

## Run
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension (VS Code will suggest it).
3. Right-click index.html > "Open with Live Server" (or click "Go Live" in the status bar).
4. The app opens at http://127.0.0.1:5500/index.html

No install or internet is needed; the app is a single self-contained HTML file.
